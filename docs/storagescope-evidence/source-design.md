# StorageScope 设计系统 · 桌面专业工具

方法论参照 [impeccable](https://github.com/pbakaus/impeccable)。本应用属 **Operate 模式**：用户来完成任务，表达让位于可扫读性、一致性与操作效率。

## 产品优先

StorageScope 首先是一个 Windows 磁盘空间分析与安全清理工具，不是海图、城市或其他视觉隐喻的展示器。

核心路径：找到空间占用 → 判断哪些能处理 → 安全释放 → 用快照追踪变化。任何视觉元素都应缩短这条路径，而不是增加阅读成本。

## 视觉原则

- **中性表面**：使用近中性深灰，不用大面积深蓝或发光底色。
- **低饱和强调色**：灰蓝只用于主操作、激活状态和链接；柔和橙色只表示可清理项或空间增长。
- **无荧光**：3D 节点以漫反射为主，自发光强度仅 0.1；取消高亮青色和强饱和节点。
- **无主题装饰**：不使用罗盘、测绘刻度、航海文案、装饰性网格或隐喻标题。
- **少容器**：工作区主要靠分隔线、留白和文字层级组织，不把每组内容包成浮动卡片。
- **直接文案**：说“扫描目录”“空间占用”“可回收空间”，不说“测绘海域”“打捞暗礁”。

## 令牌（`ui/src/App.css` `:root` 唯一事实源）

- **表面**：`--surface-0 #121315` 页底与输入 / `--surface-1 #191b1e` 侧栏、表头与结果横带 / `--surface-2 #202327` 控件与悬停 / `--surface-3 #282c31` 强悬停。
- **分隔线**：`--line #30353b` / `--line-strong #454c54`。
- **文字**：`--text #e8eaed` / `--muted #a6adb5` / `--faint #808993`。
- **操作与状态**：`--accent #8ea9c4` 灰蓝 / `--warning #c79a62` 柔和橙 / `--danger #cf7d72` / `--success #8eb59d`。
- **形状**：控件圆角 3px；导航与数据区不使用胶囊或卡片轮廓；无阴影、无发光。
- **字体**：Segoe UI / Microsoft YaHei；等宽仅用于路径与数据；表格数字使用 `tabular-nums`。

## 布局与交互

- 左侧 208px 工作流导航：01 扫描 → 02 结构 → 03 快照 → 04 差异 → 05 清理；当前项用 2px 灰蓝边线标记。
- 右侧为占满剩余宽度的数据工作区，不再限制为居中的窄网页内容。
- 品牌标直接使用磁盘与占用量线稿，副标题为“磁盘空间管理”。
- 首屏只呈现一个明确的扫描任务：带标签的路径输入、只读安全说明和扫描 / 取消状态；结果提供进入目录结构与分析可回收空间的直接动作。
- 扫描后自动进入目录结构；列表、层级图和 3D 树服务于同一组空间数据，视图切换使用分段控件。
- 清理页按“分析设置 → 保留边界 → 候选统计 → 手动清理 → 统一清单 → 执行结果”组织；不再提供基于目录名的一键安全释放。
- 目录名只提供人工复核线索。参考目录作为重复组保留锚点，排除目录不参与清理；两者的后代与祖先目标均受保护，前端选择与 Rust 执行层同时校验。
- 统一清单显示逻辑大小、路径、修改时间、判断等级与建议依据，支持类型筛选、路径搜索、定位、复制路径与重复组保留选择；同一路径只计算一次，已选目录内部的文件不重复进入删除队列。
- 执行结果区分候选逻辑大小、待清空回收站大小和已核实分配空间释放；快照差异只比较逻辑大小，不冒充卷可用空间测量。执行后同步撤下失效目标并重算候选，已合并副本不得以大文件身份重新出现。
- 清理表格固定选择框与数值列宽，路径列优先使用剩余空间；窄窗口允许表格横向滚动，不撑坏整页。
- 快照页按“记录设置 → 最新统计 → 占用趋势 → 快照记录”组织；记录包含完整时间并按最新优先排列，可一键比较最近两次。
- 差异页预选最近两次快照，支持交换基准与结果；更换选择时撤下旧报告，避免误读。结果依次展示净变化、四类文件变化、文件明细和目录净变化。
- 四类文件体积独立计算：新增、删除、增长和缩减互不混用；增长与新增使用柔和橙，缩减与删除使用柔和绿。
- 路径、重复组和动态消息具备可访问名称；目录列表支持 Enter / 空格展开；3D 树支持 R 重置视角、Esc 返回上级，快捷键不拦截输入控件或 Ctrl / Alt / Meta 组合键。
- 窗口适配 1000px 与 720px 两档宽度；3D 画布用 ResizeObserver 同步尺寸与相机比例。尊重减少动态效果偏好，关闭目录展开动画与 3D 阻尼；桌面标题栏使用深色主题。
- 页面切换不做浮起动画；差异结果直接呈现，不做整排闪烁。

## 可视化

- 空间分布组件直接消费真实扫描数据：比例条展示前 5 个一级目录，其余合并为“其他目录”，根目录直属文件独立计算；图例同时显示占比与大小。
- 3D 树采用纸雕档案模型：根目录为托盘、目录为文件夹、直属文件为叠页、折叠项为文件堆；柔和弧线表达父子关系，大小表达占用，橙色表达可清理。统一矢量徽章仅在近两层标记主导文件类型，混合内容不强行分类。
- 按真实目录数量做细节分级：超过 600 个目录默认展示 3 层，超过 250 个默认 4 层，其余最多 6 层；复杂目录深层保留前 5 项并聚合其余项，点击目录仍可继续下钻，节点预算为 900。
- 默认取景从较近位置开始，按节点及标签预留位置的真实投影检测逐步后退，兼顾深层小目录可读性与外侧分支的安全边距。顶层名称按占用优先做屏幕矩形碰撞检测，并在每次重置或 resize 后重新计算；被隐藏的名称仍可悬停查看。
- 3D 树使用 1.9 倍隐形拾取代理与单一悬停高亮环；下钻、Esc、返回按钮和面包屑均保持滚动位置，画布替换后清理旧提示。背景为中性灰，不使用地面网格或持续自转。
- 层级图降低颜色饱和度，避免彩色块抢夺注意力。
- 趋势图使用灰蓝折线与柔和状态色，网格仅承担刻度阅读功能；密集快照对时间刻度抽稀，小字节刻度取整，并为首尾标签保留空间。
