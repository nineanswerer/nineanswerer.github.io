# StorageScope 产品事实

（依据既有开发历史与明确需求整理，非新一轮访谈。）

## 是什么
Windows 桌面磁盘分析清理工具（Tauri 2 + Rust + React/TS + Three.js）。名称"存储显微镜"。

## 受众与场景
九术：大数据专业大四学生、自由职业，游戏玩家（D:\mc 30 万文件的 Minecraft 目录是首个真实数据集）。拯救者 R7000（Win10、RTX 4060）。夜间长时间使用，深色界面。中文界面，语气直接轻松。

## 核心任务
找到磁盘空间被谁吃掉 → 安全清理（回收站，可恢复）→ 长期追踪膨胀趋势。
主流程：扫描目录 → 目录结构可视化 → 快照/差异 → 清理建议 → 清理执行。

## 已确认的品牌承诺
- 3D 立体树是用户认可的核心可视化（放射布局、纸雕档案模型、类型徽章、橙色=可清理），用户明确否定过 3D 城市（"好看但没用"）。
- 界面色：低饱和灰蓝（操作）+ 柔和橙（可清理/警示）；不使用荧光效果。
- 应用图标：深蓝底 + 立体树造型（已发布 v0.1.0）。
- 安全底线：目录名不直接等于安全删除；删除只进回收站、每组重复文件至少保留一份；参考与排除目录受保护，执行前复核路径、内容和文件实体，空间结果区分逻辑大小与实际核实释放。

## 约束
- 桌面窗口默认 1200×800；单窗口全部功能。
- 性能：30 万文件目录完整分析 18.8 秒，可视化节点预算 900。
- 用户评价标准：对"找空间占用"有没有直接帮助，花架子会被否。
