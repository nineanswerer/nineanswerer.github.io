StorageScope 于 2026 年 11 月 4 日完成 Beta 工程阶段结项。当前外部测试版为 **v0.3.0-beta.2**，提供 NSIS 安装包与免安装 ZIP。公开仓库保留源码、自动化检查、性能脚本、验收记录和恢复开发说明，后续可以从 GitHub 克隆继续开发。

这次结项固定了一套可获取、可安装、可检查、可恢复开发的工程基线。版本仍处于 Beta，市场需求和外部设备兼容性留待后续验证。

## 当前产品形态

StorageScope 当前是一款**带 3D 可视化的可信磁盘分析与清理工具**。目录结构工作区提供列表、空间分布和 3D 树三种视图；快照趋势、差异比较、清理复核、诊断导出和更新检查使用各自的操作入口。

| 能力 | 当前实现 |
| --- | --- |
| 目录分析 | 扫描、取消、目录联接环检测、层级统计与三种结构视图 |
| 变化追踪 | 快照保存、差异比较与目录净变化 |
| 文件处理 | 参考与排除目录、执行前复核、回收站、重复文件合并与中断恢复 |
| 维护能力 | 本地结构化诊断、路径脱敏导出与手动更新检查 |
| 发布形态 | NSIS 安装包、免安装 ZIP、用户指南与公开验收记录 |

最初的设想是让 3D 立体树成为主要工作区，所有功能围绕它展开。当前 3D 树承担结构探索，整个应用采用多工作区协作。这个差距已经写入交接文档，作为后续产品决策的起点。

## 自动化与真实窗口验收

结项基线通过 **57 项 Rust 核心测试、8 项桌面测试和 20 项前端模型测试**。Rust 格式检查、Clippy、前端 lint、生产构建与 GitHub Actions 均已通过。

真实验收使用 Windows 桌面窗口、隔离安装目录、隔离数据目录和合成样本。安装生命周期与维护功能的实际结果如下：

| 验收项 | 实际结果 |
| --- | --- |
| beta.1 → beta.2 覆盖升级 | 文件版本更新，6 份快照保留，数据库 SHA-256 不变 |
| beta.2 卸载与重装 | 卸载移除程序和快捷方式并保留数据，重装可读取旧快照 |
| 免安装替换升级 | 1 份快照保留，主程序哈希与 release 构建一致 |
| 更新检查 | beta.1 能发现 beta.2，并打开对应 GitHub Release |
| 命令行窗口 | 安装版与免安装版启动均未发现附加命令行子进程 |
| 诊断导出 | 原生“另存为”对话框导出 94 条事件，包含取消记录，受检路径均脱敏 |

发布资产也已从 GitHub Release 重新下载。下载文件的文件名、字节数和 SHA-256 与本地发布资产一致。

## 性能记录带着样本和条件

百万文件取消样本由 1,000 个目录和每目录 1,000 个空文件组成。真实窗口自动化点击取消后，约 **2.90 ms** 开始取消，约 **48.40 ms** 出现可见的不完整结果。取消后停留在扫描结果页，用户可以继续查看已经完成的部分。

10 万文件样本完整扫描后切换到 3D 树，静止视图连续采集 120 帧：平均约 **165.02 FPS**，平均帧间隔 **6.060 ms**，p95 与最大帧间隔均为 **6.20 ms**，长任务为 **0**。

这些数字来自同一台维护机。3D 采样期间没有旋转或缩放操作，结果用于记录该次静止视图的表现。其他 GPU、高负载交互和真实大型混合目录需要独立测量。

## 后续回到 3D 树中心

后续设计方向是把 3D 场景作为主要工作区，让扫描状态、节点层级和类型标识直接呈现在场景中。选中节点后可以查看快照历史、比较变化、加入分析计划或设置保护；快照差异映射为节点的新增、删除、增长和缩减状态。

清理仍保留独立确认步骤。确认前可以回到场景检查目标及其父子关系，列表和空间分布继续承担精确检索与辅助比较。首先验证 3D 主工作区能否提高定位效率，再决定视觉和交互投入。
